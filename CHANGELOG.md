## [0.2.0] - 2026-09-29

A modernization of the whole stack and a move from a client-rendered app to a statically prerendered site, without changing the visual design or the content model.

### Added

- **Static prerendering** of every page in every language with React Router 8 framework mode, including per-page title, description, canonical URL, `hreflang` alternates, Open Graph and Twitter tags, structured data for the person, a sitemap and a social image.
- **Language in the URL** (`/es/…`, `/en/…`) with a language chooser at the site root that redirects to the visitor's language.
- **Strict Content-Security-Policy** generated per page from the hashes of its inline scripts, and a build verification step (`scripts/verify-build.mjs`) that checks it, the SEO tags, heading structure, internal links and the absence of third-party requests.
- **`404.html`** that hydrates any address, answered by GitHub Pages with a real 404 status.
- **Self-hosted variable fonts**, with the two above-the-fold files preloaded.
- **End-to-end tests** (114) in real Chrome for desktop and mobile: accessibility with colour contrast in both themes and languages, CSP, rendering without JavaScript, redirects, 404 responses, theme, language and the contact form.
- **Lighthouse CI** with score floors, a **bundle-size budget**, **coverage floors**, **knip** for unused code, **CodeQL**, **release-please**, actions pinned by SHA, `SECURITY.md`, `CODE_OF_CONDUCT.md` and `CODEOWNERS`.
- Git hooks (lint-staged, type-check, commitlint) through lefthook.
- A Pages-like preview server (`npm run preview`) with base path, gzip and 404 semantics.
- A framework-free `domain` layer, a `services` layer for ports and a `theme` layer, with the allowed imports enforced by ESLint.

### Changed

- **Every dependency moved to its latest major**: React 19, React Router 8, Vite 8, Vitest 5, ESLint 10, Tailwind CSS 4, Zod 4, TypeScript 6, Node 24 as baseline. `npm audit` reports no vulnerabilities.
- The contact form uses **React 19 form actions**; its logic is a pure, unit-tested function.
- Content is validated when the build or dev server starts instead of at runtime, keeping the schema library out of the initial bundle.
- Entrance animations are pure CSS (scroll-driven where supported) instead of a JavaScript library.
- The theme is a small in-house implementation with an inline head script instead of a library.
- The content repository is split into small interfaces (`ProjectRepository`, `PillRepository`, `AboutRepository`).
- Accessibility fixes found by the browser audits: colour tokens that meet WCAG AA in both themes (including a dedicated accent colour for text), heading levels without gaps, underlined links inside text, and keyboard-reachable code blocks.
- The design-system primitives are written for React 19 (`ref` as a prop, `data-slot`).
- ESLint uses strict type-aware rules; TypeScript uses `verbatimModuleSyntax`, `erasableSyntaxOnly` and `noUncheckedIndexedAccess`.

### Removed

- The client-side-only router setup, the motion library, `next-themes`, `react-hook-form` and its resolver, and the `useDocumentMeta` hook (replaced by route `meta`).
- Google Fonts.

### Breaking changes

- URLs now include the language (`/projects` became `/en/projects` and `/es/projects`).
- Node.js 22.22 or newer is required.
- The build output moved from `dist/` to `build/client/`.

## [0.1.0] - 2026-09-28

Initial public release. The project is a ground-up restructuring of a generated prototype into a maintainable, tested and documented application.

### Added

- Bilingual (ES/EN) UI with typed dictionaries, browser-language detection and persisted preference.
- Content layer: one JSON file per entity with per-locale translations, validated by Zod and exposed through a `ContentRepository` interface.
- Feature modules for home, projects, pills, about, contact and not-found pages.
- Accent-insensitive search and type filters for projects; search for pills.
- Project cover images and galleries with localized alt texts.
- Contact form with localized validation, running in demo mode behind a `ContactService` abstraction.
- Light, dark and system themes without a flash of the wrong theme.
- Accessibility: skip link, landmarks, `aria-current` navigation, labelled controls, reduced-motion support.
- Route-level code splitting and a top-level error boundary.
- Vitest and Testing Library suite (47 tests).
- GitHub Actions for CI and GitHub Pages deployment, with a `404.html` fallback for deep links.
- ESLint (with `jsx-a11y`), Prettier, EditorConfig and strict TypeScript settings.
- Documentation: README, contributing guide, architecture overview and decision records.
- Issue and pull request templates, and Dependabot configuration.

### Changed

- Project slugs are now English and stable across locales (for example `sivia-visual-inspection`).
- Navigation uses router links everywhere, so it no longer triggers full page reloads.
- The 404 page is localized, themed and shown for unknown project and pill slugs instead of redirecting.
- The contact `mailto:` link is built once from a plain address and no longer duplicates the `body` parameter.

### Removed

- Unused UI components, hooks, images and roughly 40 unused runtime dependencies.
- The `lovable-tagger` plugin and the duplicate lockfile (`bun.lockb`); npm is the single package manager.
- The unregistered `@tailwindcss/typography` classes and unused Tailwind animations and sidebar tokens.
